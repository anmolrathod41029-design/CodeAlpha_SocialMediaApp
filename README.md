# 📱 CodeAlpha Social Media Platform

A modern and responsive Mini Social Media Web Application built using HTML, CSS and JavaScript during the CodeAlpha Internship Program.

## 🚀 Project Overview

This project is a dynamic social media platform where users can create posts, interact with others, like posts, comment, follow profiles and explore a modern social feed experience.

The application is designed with an attractive UI, responsive layout and interactive features similar to modern social media apps.


# ✨ Features

- 👤 User Profile Section
- 📝 Create & Share Posts
- ❤️ Like System
- 💬 Comment System
- ➕ Follow / Unfollow Users
- 🌙 Dark Mode Toggle
- 🔍 Search Users & Posts
- 📱 Fully Responsive Design
- 🔔 Toast Notifications
- 🎨 Modern Glassmorphism UI
- ⚡ Dynamic JavaScript Functionality
- 📸 Story/Profile Cards
- 🧠 Interactive User Experience
  

# 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- 

# 🎯 Objective

The objective of this project is to simulate the core functionality of a real-world social media application while improving frontend development skills and user interface design concepts.
